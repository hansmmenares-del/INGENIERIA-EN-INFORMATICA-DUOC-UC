CONSTRUCTOR:
Si quiero instanciar un objeto debo pasarle ciertos parametros, de otro modo no se puede crear el objeto.
	Por ej: {
		Para crear la clase "Rectangulo",
		-> Debe tener:
		Altura:
		Perimetro:
		Area:
		
		-> Metodo:
		mostrar()
		
		
		-> Para declararlo se hace:
		New Rectangulo (15,10)
		Constructor recibe ciertos parametros
		Constructor(base,altura)
		
		// Constructor sirve para inicializar un objeto
	}

EL CONSTRUCTOR NO TIENE NINGUN RETORNO, solo sirve para instanciar.
